Get started in minutes

Install Sanin

From APK to your first episode — here's everything you need to know.

01

Download the APK

Grab app-google-arm64-v8a-release.apk from the latest release. On your TV, open the browser, go to the releases page, and download it — or send it from your phone with LocalSend or ADB.

Releases →
02

Install & open

Open the downloaded file — the system package installer handles the rest. If it says "Install blocked", allow unknown apps for your browser in TV Settings → Security.

Android 5.0+ (API 21) · no Samsung TVs (Tizen)

03

Sign in to track

Connect your AniList or MyAnimeList account to sync your watchlist, track progress, and get recommendations. Works fully offline without an account too.

Add sources

Install extensions

Sanin uses a Tachiyomi-compatible extension system. Extensions are separate APK packages that add streaming sources. Start with the recommended repo — or add any other from the community.

Recommended — one tap in-app, or copy
yuzono/anime-repo · index.min.json
phisher98/…/repo.json

Android only · repos are how sources are installed

Step 1

In Sanin go to Settings → Extensions and tap the + button.

Step 2

Paste the repo URL above (short form works too — username/repo/branch).

Step 3

Available extensions appear in the Available tab. Tap Install on any source you want.

Step 4

Search or browse for an anime, tap an episode, pick a source — playback starts instantly with full gesture and D-pad controls.
